TouchGFX Designer Customization Guide for 2048 Game
=======================================================

1. TEXT SETUP (PRIORITY 1):
   - Go to "Texts" tab
   - Add these Text IDs:
     * T_TILE_NUMBER: "0" (for tile values)
     * T_SCORE_LABEL: "SCORE"  
     * T_SCORE_VALUE: "0" (for score display)
     * T_GAME_OVER: "GAME OVER"
     * T_GAME_WON: "YOU WON!"
     * T_INSTRUCTIONS: "Tilt to move, blue button to reset"

2. FONTS SETUP:
   - Go to "Typography" tab
   - Create fonts for:
     * Tile numbers (medium size, bold)
     * Score display (small size)
     * Game messages (large size, bold)

3. SCREEN LAYOUT:
   - Go to "Screens" → Screen1
   - Adjust screen dimensions if needed
   - Position game board widget
   - Add text areas for score and messages

4. COLORS:
   - Go to "Themes" tab
   - Set color scheme to match 2048 style:
     * Background: Light beige (#FAF8EF)
     * Board: Dark beige (#BBADA0)
     * Tiles: See color codes in TouchGFX_Text_Resources.txt

5. INTERACTIONS (OPTIONAL):
   - Add button interactions
   - Set up gesture handling for swipe controls

AFTER MAKING CHANGES:
- Click "Generate Code" in TouchGFX Designer
- Go back to STM32CubeIDE
- Rebuild project
- Flash to board

The text areas in Screen1View.cpp will automatically use the Text IDs you create.
